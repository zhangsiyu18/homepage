🌙 智能感应小夜灯

基于 ESP32 的人体感应 + 环境光检测自动夜灯 · 3D 打印个性化外壳

📖 项目简介

一个会"看天色、认人"的小夜灯：天黑时有人靠近自动亮灯，人离开后延时熄灭，白天不亮。

🧠 工作逻辑

简单来说：天黑 + 有人 → 亮灯；人走 30 秒 → 熄灯；白天 → 一直不亮。

🖨️ 3D 结构设计

设计要点

💡 透光外罩：使用半透明材料（PLA/树脂）或磨砂处理，让光线均匀漫射
👤 传感器开孔：PIR 的菲涅尔透镜必须外露，不能被外壳挡住；BH1750 也要开窗接收环境光
🏠 底座结构：预留 ESP32 + 电池仓 + Type-C 充电口，建议卡扣或磁吸开合
✨ 造型建议：弯月 / 猫咪 / 星星，按你喜好自由发挥！

调试小技巧

✓ 测 PIR：手在传感器前晃动，看灯是否亮
✓ 测光照：用手遮住光感器，灯才会亮
✓ 调延时：拧 PIR 上的橙色旋钮（控制亮灯时长）
✓ 调灵敏度：拧 PIR 上的蓝色旋钮（控制感应距离）

❓ 常见问题

问题可能原因解决方法
灯一直不亮BH1750 被遮挡 / 阈值太低检查传感器开孔，调高亮度阈值
灯一直亮PIR 延时电位器调太大调小 HC-SR501 上的延时旋钮
灯闪烁PIR 刚上电不稳定等待 30-60 秒让传感器稳定
白天也亮BH1750 接反/损坏检查 I2C 接线和地址
